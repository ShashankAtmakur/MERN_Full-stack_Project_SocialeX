# SocialeX — Client

This is the React frontend for SocialeX. It's built with Create React App and connects to the backend API running on port 6001 by default.

## Requirements
- Node.js and npm (or yarn)

## Install

```powershell
cd client
npm install
```

## Available scripts
- `npm start` — start the dev server (CRA) on port 3000 by default.
- `npm build` — create a production build.
- `npm test` — run tests (CRA test runner).

## Configuration
- The client is configured to call the backend at `http://localhost:6001` from several places in `src/` (notably `src/context/AuthenticationContextProvider.jsx`). If you run the server on a different port or host, update those URLs.

## Authentication notes
- The login and register flows now normalize emails before sending to the backend (trim + lowercase). If you experience login failures, inspect the Network request in DevTools to confirm the JSON payload contains `email` and `password` fields and that `Content-Type: application/json` is set.

## Debugging tips
- Open browser DevTools → Network → make the POST request to `/login` and inspect request payload & server response.
- Console logs: the authentication context now logs success and prints server error messages to the console to make debugging easier.

## Useful files
- `src/context/AuthenticationContextProvider.jsx` — handles login/register and localStorage.
